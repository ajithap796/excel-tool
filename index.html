Typography (Whole Sheet)

Format GST 2A/2B

Tick the downloaded 2A/2B sheets to format. Each sheet: top rows removed, merged headers unmerged and collapsed into one header row, filter applied, top row frozen. Sheets that already have a filter are skipped, so running twice is safe.

2B vs Books: Summary + Match

Scan the workbook, confirm sheets and columns, then build an invoice-level match sheet and a linked summary. Tier 1: Date + GSTIN + Name + Invoice No + Taxable + GST. Tier 2: Date + fuzzy Invoice No + fuzzy Name + Taxable.

Column mapping (auto-detected, change if wrong)

Rows 10, 11, 16 and 20 of the summary (RCM/expense adds, amended invoices) stay manual. Credit notes and RCM come from their own sheets.

Dynamic Pivot Summary

Highlight your data table (with headers) and load to build a structured visual summary. The source range is remembered even if you change sheets.

Amount to Words

Select number cells. Words (lakh / crore) are written to the output column you type. Nothing is overwritten: if the output cells are not empty, the tool stops.

Split Sheet by Column

Highlight a data table with headers, load, pick the column. One new sheet per unique value, header row copied. Maximum 100 groups.

Invoice Print Setup

Select the invoice area. One click sets print area, A4, fit to one page, margins and centering. Then press Ctrl+P and choose Save as PDF.

Compliance Data Masker

Select a range with sensitive values. Formula cells are never overwritten. Cells that do not fit the chosen profile are left untouched and counted.
